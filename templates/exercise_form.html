Regular expression source

Type a regex and the target DFA preview below updates from it. The manual DFA fields become read-only while this mode is active.

Supported syntax
Use single-character symbols, parentheses, union |, star *, and implicit concatenation such as ab.
Example
(a|b)*ab generates the language of strings ending in ab.

NFA JSON source

Paste an NFA in JSON form. The app converts it to a DFA target and shows the generated result below.

Required keys
states, alphabet, start, accepting, and transitions.
Epsilon transitions
Use "ε" or an empty-string key for epsilon transitions.
Choose a source type. In DFA mode you can edit the target directly. In regex / NFA mode the target preview is generated from the source input.

Visual editor

Author the DFA directly on the canvas, then keep the structured text view in sync. Click a transition and drag its endpoint into a different state. The reconnect button is kept as a fallback.
